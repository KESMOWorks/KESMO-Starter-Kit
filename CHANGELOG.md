# Changelog

All notable changes to the KESMO Starter Kit will be documented in this file.

The format follows a simple version-based structure so future KESMO tools can clearly track shared improvements.

## [1.2.0] - 2026-08-04

### Added

- Configurable tool homepage label for shared footer navigation
- Shared `[hidden]` styling for conditional interface elements
- Exact GitHub Pages activation instructions
- Explicit off-stream Google Search Console guidance
- Pre-publication template-remnant audit guidance

### Changed

- Standardized About page Hero title as `About the [Tool Name]`
- Standardized Privacy page Hero title as `Privacy Policy`
- Standardized About and Privacy contact formatting
- Updated Starter Kit version references for consistency
- Expanded new-tool documentation using lessons from the Break-Even Calculator

## [1.1.0]

### Added

* Reusable shared Hero component
* Configurable Hero content through data attributes
* Shared Header, Hero, and Footer page architecture
* Official KESMO YouTube link in shared navigation
* Expanded publishing and verification documentation
* Livestream documentation and safety guidance

### Changed

* Standardized shared component rendering across Home, About, Privacy, and 404 pages
* Removed duplicated Hero markup from individual pages
* Clarified the Starter Kit as the source of truth for shared KESMO implementation
* Expanded the reusable development and publishing workflow

## [1.0.0] - 2026-07-25

### Added

* Reusable KESMO website foundation
* Shared KESMO design system
* Mobile-first responsive layout
* Accessible semantic page structure
* Shared header and footer components
* Active navigation highlighting
* KESMO logo and favicon support
* Shared KESMO social sharing image
* About page
* Privacy Policy foundation
* Custom GitHub Pages 404 page
* `robots.txt`
* `sitemap.xml`
* Open Graph metadata
* X/Twitter Card metadata
* Structured data support
* Reduced-motion support
* Print styles
* Central KESMO configuration in `components.js`
* Support email configuration
* Shared footer contact link
* GitHub Pages compatibility
* Professional project documentation

### Changed

* KESMO Starter Kit became the shared reference implementation for future KESMO tools
* Header styling was aligned with the KESMO Pricing Calculator
* Shared branding assets were organized under `assets/branding/`
* The KESMO logo links to the current tool homepage
* The footer includes a future link to the central KESMO tools page
* The About page includes general KESMO contact information
* The Privacy page includes privacy-specific contact information

### Security and Privacy

* The Starter Kit is blocked from search indexing by default
* No analytics are included by default
* No advertising is included by default
* No cookies or browser storage are used by default
* No user information is transmitted by default
